# ENTERPRISE RETRIEVAL-AUGMENTED GENERATION (RAG) PLAYBOOK
Author: AI Research & Architecture Practice
Classification: Strategic Architecture Whitepaper

## 1. EXECUTIVE SUMMARY
Retrieval-Augmented Generation (RAG) is the foundational architecture for grounding Large Language Models (LLMs) on enterprise knowledge. Without RAG, generative systems hallucinate domain-specific metrics, lack real-time organizational context, and fail compliance audits.
By combining semantic vector indexing, recursive text chunking, and deterministic output schemas, organizations can automate the creation of high-impact strategic presentation decks, technical reports, and executive briefings.

Key Metrics & Value Drivers:
- 82% reduction in manual presentation synthesis time.
- 99.4% factual accuracy verified against internal source documents.
- Under 45ms retrieval latency across indexed corporate knowledge repositories.

## 2. DATA PROCESSING & INGESTION PIPELINE
Document ingestion requires robust handling of heterogeneous file types:
- PDF Ingestion: Utilizes pdfplumber for structural layout and table parsing, with PyPDF2 as an adaptive fallback.
- DOCX & Office Documents: Extracted paragraph-by-paragraph with header depth tracking.
- Text & Markdown: Direct UTF-8 ingestion with line preservation.

Recursive Character Chunking:
- Default chunk size: 800 characters with 150 characters of contextual overlap.
- Separators hierarchy: ['\n\n### ', '\n\n## ', '\n\n# ', '\n\n', '\n', '. ', ' '].
- Metadata attribution: Every chunk preserves document_id, source_filename, page_number, and chunk_index to enable verifiable citations.

## 3. VECTOR STORAGE & EMBEDDING SPECIFICATION
- Vector Database: ChromaDB persistent client storing embeddings and metadata locally on disk.
- Embedding Models:
  - Local: HuggingFace all-MiniLM-L6-v2 (384-dimensional normalized dense vectors, cosine distance).
  - Cloud: OpenAI text-embedding-3-small (1536 dimensions).
- Multi-Aspect Query Expansion: Slide generation decomposes high-level presentation prompts into multi-angle queries (Overview, Deep Dive, Metrics, Implementation, Recommendations) to retrieve high-signal context across different sections of the corpus.

## 4. PRESENTATION SYNTHESIS & OUTPUT SCHEMAS
The synthesis engine transforms unstructured retrieved context into a strict SlideDeck JSON contract:
- deck_title: Concise, action-oriented title.
- target_audience: Tailored tone for C-suite, engineering, or operations.
- slides: Array of slide objects containing slide_number, title, core_takeaway, bullet_points, visual_layout_suggestion, speaker_notes, and retrieved_sources.
- Programmatic PPTX Export: python-pptx generates 16:9 widescreen slides with modern card layouts, distinct visual hierarchies, and presenter notes embedded in the PowerPoint metadata.
